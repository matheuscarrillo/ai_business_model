# ai_business_model
Developping model of business for better serve users


Antes de rodar, crie um .env, na raiz do projeto, com as seguintes informações:

```bash
MODEL_NAME="gpt-5.6-luna"
OPENAI_API_KEY=SITE OPENAI

```

Em seguida, crie uma env e execute o comando abaixo, dentro da env:

```
pip instal -e .
```
